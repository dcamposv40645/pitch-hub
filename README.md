# Pitch Hub

Chrome extension that detects the musical key of whatever's playing in your browser tab — in real time.

## Features

- Live key detection from any tab (YouTube, Spotify, SoundCloud, etc.)
- Shows the key, scale quality, and diatonic chords
- Identify Song — fingerprints the audio via ACRCloud to tell you what's playing
- Essentia beta mode for experimental analysis

## Install

1. Clone or download this repo
2. Go to `chrome://extensions`, enable Developer Mode
3. Click "Load unpacked" and select the project folder
